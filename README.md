# mopup

100ブロックのアンプリファイドワールドで、地上（y>=64）の敵モブを掃討するミニゲームMOD（Fabric 1.21.11）

## 導入方法

- Minecraft Java Edition 1.21.11
- Fabric Loader 0.19.0 以上
- Fabric API 0.141.6+1.21.11

`mopup-x.x.x.jar` を `mods` フォルダに配置してください。

## 遊び方

1. クリエイティブ・ハード・アンプリファイドでワールドを新規作成
2. （任意）`/mopup item` で初期アイテム（シュルカーボックス）を取得
3. `/mopup setup` でゲーム開始（現在地中心に100ブロックのワールドボーダー、時間を真夜中で固定、サバイバルモードへ）
4. 地上の敵モブを全滅させ、30秒間 0 体を維持すれば勝利

`/mopup setup` はゲーム中・勝利後でも実行でき、ゲームをやり直せます。

### 画面表示

- ボスバー: 地上の敵モブ数 / 勝利までのカウントダウン
- アクションバー: 現在のY座標 / 発光までの時間
- 1分に1度、10秒間ターゲットモブが発光します

### ターゲットモブ

ゾンビ（チビゾンビ・村人ゾンビ・ゾンビホース・ハスク・ラクダハスク）、クリーパー、スケルトン、クモ、エンダーマン、ウィッチ、ボグド、ストレイ、パーチド、スケルトンホース、スパイダージョッキー、チキンジョッキー
