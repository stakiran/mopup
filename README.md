# 掃討マイクラ
100ブロックのワールドで、地上の敵モブを掃討するミニゲームMOD。

[![mopup demoplay](https://img.youtube.com/vi/RwwMX-0IuCU/maxresdefault.jpg)](https://www.youtube.com/watch?v=RwwMX-0IuCU)

## 導入方法
- Minecraft Java Edition 1.21.11
- Fabric Loader 0.19.0 以上
- Fabric API 0.141.6+1.21.11

`mopup-x.x.x.jar` を `mods` フォルダに配置してください。

## 遊び方
1. クリエイティブ・ハード・でワールドを新規作成します
2. `/mopup` でゲームを開始します（持ち物がクリアされ、初期アイテムが配られます）
3. 地上の敵モブを全滅させて 30 秒間維持すれば勝利です。死亡するか高さがはみ出たらゲームオーバーです

### 高さからはみ出たら、とは？
直下掘りやブロック積みなどで地上から距離を置けば勝ててしまうので、封じています。

`y < 60` または `(その地形の最高点+3) < y` に行った時点でゲームオーバーです。

### 見方
- 規模について
    - 敵 MOB が湧けるマス数から「地形のサイズ」を計算したものです
    - 今回の地形がどれだけ複雑か、広いか、起伏が激しいかの目安にできます
- スコアについて
    - 規模に応じた基準タイム（最低でも 3:00 以上）からの開きを見ます
    - スコア 50 が標準です。まずは 50 を目指しましょう
- 発光について
    - 1分に1度、10秒間ターゲットモブが発光します

### ターゲットモブ
この MOD では以下を敵とみなします。

- ゾンビ（チビゾンビ・村人ゾンビ・ゾンビホース・ハスク・ラクダハスク）、クリーパー、スケルトン、クモ、エンダーマン、ウィッチ、ボグド、ストレイ、パーチド、スケルトンホース、スパイダージョッキー、チキンジョッキー
